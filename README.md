# 🎼 Musician AI Manager

AI Manager for Freelance Musicians

---

## Vision

音楽家が本来の創作・演奏活動に集中できるよう、
仕事の管理をAIが代行する。

---

## Project Goal

複数の媒体（LINE・Instagram・Facebook・X・Gmail等）から届く仕事の連絡を整理し、

* 案件化
* タスク管理
* 返信作成
* 請求書作成

までを一元管理できるAIマネージャーアプリを開発する。

---

## Target Users

* 演奏家
* 作編曲家
* 音楽講師
* ステージマネージャー
* フリーランス音楽家
